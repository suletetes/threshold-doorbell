# ui/

Screens. Captions are the primary interface, not a secondary label.

1. **Alert** — full-bleed visitor thumbnail, distinct haptic, single primary action.
2. **Conversation** — video top third; captions dominate the rest at adjustable size/contrast; turn labels;
   confidence styling.
3. **Reply bar** — three Bedrock Smart Replies + free text; sending state shows "speaking at your door…".
4. **Transcript history** — searchable list of past door conversations.
5. **Settings** — Privacy/Clarity toggle, caption typography, haptic patterns, language, privacy zones.

Every screen must be fully usable with sound off and screen reader on.
