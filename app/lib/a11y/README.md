# a11y/

Accessibility is the product, not a feature. Target **WCAG 2.2 AA** — which Ring's own partner UX guide
mandates.

- Large, adjustable, high-contrast caption typography.
- Full TalkBack (Android) / VoiceOver (iOS) support and semantic labels.
- No information conveyed by sound alone; no critical action requiring hearing.
- Respect OS text-scaling and reduce-motion settings.
